云记 - 语言包说明
================

【目录作用】
本目录下的每个 .json 文件就是一个界面语言包。程序启动时会自动扫描本目录，
设置页「语言」标签页里列出的可切换语言，就是这里的文件。

【如何创建新语言】
1. 复制一份现有文件（推荐复制 zh-CN.json，它的条目最全）；
2. 把文件名改成目标语言代码，例如 ja-JP.json、ko-KR.json、fr-FR.json；
   文件名就是语言代码，只能用字母、数字和连字符；
3. 打开文件，先改开头的 $meta 部分：
     code        语言代码，必须与文件名一致
     name        语言名（英文，便于程序识别）
     nativeName  语言名（用该语言自己的写法，显示在切换下拉里）
     version     你自己定的版本号，整数
     fallback    留空 null；如果你想先回退到另一种语言再回退到中文，
                 可以填例如 "zh-TW"（港台用语可只翻译与台湾不同的少数条目）
4. 逐条翻译下面的内容。冒号左边的 key 不要改，只改右边的文字；
5. 保存后回到程序 → 设置 → 语言，点「刷新」即可看到新语言。

【几个要注意的地方】
- 文件必须保存为 UTF-8 编码（无 BOM）。
- 文字里的 {name} 是占位符，会替换成实际内容，请保留原样，例如 {count}、{percent}。
- 少翻译几条不会出错：缺失的条目会自动回退显示简体中文。
- 如果文件内容有语法错误（比如少了逗号），设置页会把该文件标灰并显示出错原因，
  这时候其它语言不受影响，程序也不会打不开。
- 删除本目录下的文件后重启程序，会重新释放官方默认的三份语言文件。
- 官方模板更新时不会覆盖你改过的文件，而是另存一份 xxx.template.json 供你对照。

【随程序内置的默认语言】
  zh-CN.json   简体中文
  zh-TW.json   繁體中文
  en-US.json   English
